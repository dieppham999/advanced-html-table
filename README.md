# [Thực hành] Tạo bảng nâng cao

## 1. Mục tiêu

Thực hành xây dựng bảng thời khóa biểu bằng HTML, sử dụng các thuộc tính `colspan`, `rowspan` và CSS để tạo bảng có cấu trúc nâng cao.

## 2. Yêu cầu bài thực hành

- Tạo trang HTML hiển thị bảng thời khóa biểu.
- Sử dụng thẻ `<table>` để xây dựng bảng.
- Sử dụng `<tr>` để tạo hàng, `<th>` để tạo tiêu đề và `<td>` để tạo ô dữ liệu.
- Sử dụng `colspan` để gộp các ô theo chiều ngang.
- Sử dụng `rowspan` để gộp các ô theo chiều dọc.
- Sử dụng CSS để trang trí và định dạng bảng.
- Đưa mã nguồn lên GitHub.

## 3. Cấu trúc dự án

```text
advanced-html-table/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## 4. Kiến thức áp dụng

| Thành phần | Chức năng |
|---|---|
| `<table>` | Tạo bảng |
| `<tr>` | Tạo hàng |
| `<th>` | Tạo ô tiêu đề |
| `<td>` | Tạo ô dữ liệu |
| `colspan` | Gộp nhiều cột |
| `rowspan` | Gộp nhiều hàng |
| CSS | Định dạng giao diện bảng |

## 5. Kết quả mong đợi

- Bảng thời khóa biểu hiển thị đúng cấu trúc mẫu.
- Các ô được gộp chính xác bằng `colspan` và `rowspan`.
- Giao diện được định dạng bằng CSS riêng.
- Mã nguồn được quản lý và lưu trữ trên GitHub.
